# Alycia Manuele — 7 Anos de Pura Magia

Uma experiência web cinematográfica de nível internacional, concebida e desenvolvida com amor infinito para homenagear os 7 anos de vida de Alycia Manuele. Inspirada no padrão de precisão, elegância e impacto visual da Apple, a plataforma combina scrollytelling fluido, microinterações táteis, síntese sonora etérea e renderização tridimensional interativa.

---

## 🌟 Destaques da Experiência

1. **Abertura Monumental (Hero Cinematográfico):**
   - Tipografia de alto impacto com gradiente aurora e reflexos de luz.
   - Partículas estelares em tempo real (Starfield Canvas) com física acelerada pelo scroll.
   - Orbe solar em órbita com halo de refração de vidro fosco.

2. **Especificações de Uma Garota Extraordinária:**
   - Releitura poética das clássicas páginas de produto da Apple:
     - *Coração Puro Bionic 7.0:* Bondade e afeto infinitos.
     - *Energia Solar Contínua:* 14+ horas de brincadeiras e imaginação.
     - *Olhar Retina Encantado:* Percepção profunda de beleza no mundo.
     - *Gargalhada de Cristal:* Frequência harmônica de pura felicidade.
     - *Vínculo Sem Fio Ultrarrápido:* Conexão eterna de coração para coração com o papai.

3. **Linha do Tempo (0 a 7 Anos):**
   - Linha do tempo interativa navegável ano a ano, revelando memórias, citações emocionantes e marcos do nascimento até os sete anos.

4. **Mural de Talentos & Superpoderes (Bento Grid):**
   - Estrutura tátil de cards dinâmicos destacando arte, criatividade, empatia com os animais, música, dança e raciocínio brilhante.

5. **The Memory Vault (Pilha 3D de Memórias Flutuantes):**
   - Cartões fotográficos translúcidos com física orgânica de sobreposição 3D, expansão em alta definição e gerenciador integrado para inserção das fotos reais.

6. **Carta ao Futuro & Grand Finale:**
   - Mensagem eterna do pai para Alycia, com disparo interativo de chuva de estrelas cadentes (*Celestial Starburst*).

7. **Motor Sonoro Procedural (Web Audio API):**
   - Síntese acústica cristalina gerada diretamente pelo navegador, sem dependência de arquivos externos ou latência de rede.

---

## 🛠️ Tecnologias & Engenharia

- **Core:** React 19, TypeScript, Vite 6
- **Estilização:** Tailwind CSS v4, Glassmorphism de Alto Padrão
- **Animações & Física:** Framer Motion 12, Canvas 2D acelerado
- **Áudio:** Web Audio API Procedural
- **Efeitos Especiais:** Canvas Confetti Starburst

## 🚀 Como Executar Localmente

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```
